# Fonts

`RobotoMono.ttf` (SIL Open Font License 1.1, see `RobotoMono-OFL.txt`) is
here for one reason: the DXF viewer renders a drawing's text by reading
glyphs out of a real font file, and a drawing without its dimensions and
labels is not a drawing anyone can work from.

It is not used anywhere else in the application's typography.
